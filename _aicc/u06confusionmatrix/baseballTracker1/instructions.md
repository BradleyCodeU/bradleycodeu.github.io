


The Design Thinking process involves multiple steps... empathize, define, ideate, prototype, build, and test

In Part 1, you will complete the first 2 steps of the Design Thinking process: Empathize and Define

```
The overall goal is to log each pitch by type and outcome, and then get the analytics in the top table in real time.   Ideally, other points like performance by inning and by batter would also be tracked.  Then as the coach is calling the pitches, they can refer to not only how the pitcher is doing on each pitch type for the game but also how each batter is responding.  
The user wants a lot of user friendly buttons and selection options.  
Overall kind of flow:
* Input pitcher info and game info
* Input batter # and begin "at bat"
* Click pitch and select type and outcome
System will recognize an in play out/fair, strikeout, error, or walk, then will progress to next batter, or next inning if 3rd out when applicable
```

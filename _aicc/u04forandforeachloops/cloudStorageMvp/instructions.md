## Step-by-Step Supabase Setup Guide

### Step 1: Create a Supabase Account & Project

1. Go to supabase.com and click Sign Up or Log In (logging in with GitHub is easiest).

2. On your dashboard, click + New Project.

3. Fill in your project details:

    - Name: Cloud-Storage-MVP (or any name you like)

    - Database Password: Enter a strong password or generate one (save it somewhere safe)

    - Region: Select the region closest to you

4. Click Create new project and wait 1 minute for Supabase to build your cloud database

### Step 2: Create the Database Table

1. On the left sidebar of your Supabase dashboard, click the SQL Editor tab (this icon >_).

2. Click + New 

3. Copy and paste the SQL code below into the editor and then click the green Run button in the top-left (or press Ctrl+Enter). On the “Potential issue detected” popup, click “Run with RLS.” You should see “Running“ and then “Success. No rows returned.”

```
-- Create a table with two columns id and content
create table public.messages (
  id int generated by default as identity primary key,
  content text
);

alter table public.messages enable row level security;

-- Allow anyone (including anonymous users) to READ messages
create policy "Allow public select"
on public.messages
for select
to public
using (true);

-- Allow anyone (including anonymous users) to INSERT messages
create policy "Allow public insert"
on public.messages
for insert
to public
with check (true);
```

### Step 3: Get Your API Credentials

1. Click the green Connect button at the top-center of the screen.

2. Scroll down to Step 2 Add Files:

    - NEXT_PUBLIC_SUPABASE_URL= : Copy the URL after the equals sign. This is your URL. 

    - NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY= : Copy this long key string after the equals sign. This is your KEY. It should start with “sb_publishable_”

3. Paste both strings into your JavaScript code where indicated (SUPABASE_URL and SUPABASE_KEY):
